# @z-todo/core

z-todo 的领域核心。这里只放纯函数：输入数据，返回结果，不读写数据库、不发网络请求、不读系统时钟。
ESLint 会拦住 `fetch`、`Date.now()`、`window`、Tauri、sql.js、Node 内置模块等导入；需要「现在」时由调用方传入时间戳。

规划中的模块（技术方案「工程目录结构」一节）：

| 目录 | 内容 | 状态 |
| --- | --- | --- |
| `time.ts` | 本地日期归属、日界线 | 已有 |
| `deps/` | 依赖图、环检测、细化时的依赖继承 | 环检测已有 |
| `status/` | 主任务与子任务状态机 | M1 第 2 步 |
| `schedule/` | 排程校验器、逾期判断、可行性检查 | M1 第 2 步 |
| `metrics/` | 区间求和与并集、按日切分、完整度 | M1 第 2 步 |
| `strain/` | 负荷公式、恢复度、参数校准 | M3 |
| `recurrence/` | 周期展开与结算 | M2 |
| `recommend/` | 按精力推荐打分 | M3 |
